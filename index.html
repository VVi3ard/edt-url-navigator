🛠️ Инструкция по установке в 1C:EDT

  1. В главном меню 1C:EDT выберите: Справка (Help) → Установить новое ПО... (Install New Software...).
  2. Нажмите кнопку Добавить... (Add...).
  3. Укажите:
    • Имя: 1C:EDT URL Navigator
    • Расположение: https://vvi3ard.github.io/edt-url-navigator/
  4. Нажмите Добавить.
  5. Отметьте группу 1C:EDT URL Navigator Feature и нажмите Далее (Next).
  6. Примите лицензионное соглашение и нажмите Готово (Finish).
  7. После завершения установки перезапустите 1C:EDT.

🔄 Обновление плагина

После добавления репозитория плагин будет автоматически проверяться на наличие обновлений при стандартной проверке в 1C:EDT: Справка → Проверить наличие обновлений (Check for Updates).
