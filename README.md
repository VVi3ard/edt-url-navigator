# 1C:EDT URL Navigator

Плагин для **1C:Enterprise Development Tools (1C:EDT)** и мод для **Claude Code**, обеспечивающие мгновенный переход к модулям 1С, строкам кода, методам, объектам метаданных и их реквизитам по кликабельным ссылкам прямо из чата Claude Code (терминал и Claude Desktop).

---

## 💡 Как это работает

Решение состоит из двух компонентов:

1. **Плагин для 1C:EDT (`com.github.vvi3ard.dt.navigator`)**:
   - Встраивается в 1C:EDT и запускает легковесный локальный HTTP-шлюз на порту `18321` (`127.0.0.1:18321`).
   - При получении запроса мгновенно находит целевой модуль или объект метаданных среди проектов рабочей области (воркспейса) EDT.
   - Открывает соответствующий редактор (BSL-редактор с переходом к строке/методу или визуальный редактор метаданных с позиционированием на реквизит и подсветкой в дереве навигатора) и активирует окно EDT.

2. **Мод для Claude Code (`edt-links`)**:
   - Устанавливается из встроенного маркетплейса плагинов Claude Code (`claude-mod`).
   - Перехватывает клики по ссылкам вида `([EDT](http://127.0.0.1:18321/open?...))` на уровне UI-компонента `AssistantMessage`.
   - Отправляет фоновый `curl`-запрос напрямую в локальный шлюз EDT **без открытия вкладки в веб-браузере** и отображает нативный тост: `Opened in EDT` или `Not found in EDT`.

> [!NOTE]
> **Работает только в Claude Code:**  
> Решение спроектировано под архитектуру расширений Claude Code, позволяющую перехватывать клики по ссылкам в терминале и приложении без запуска браузера. Другие ассистенты (Codex, Cursor, Copilot) не поддерживаются.

> [!IMPORTANT]
> **Прямой UTF-8 без percent-encoding (`%XX`):**  
> Все ссылки формируются **чистым текстом на русском языке**:  
> `http://127.0.0.1:18321/open?module=ОбщийМодуль.ОбщегоНазначенияКлиентСервер&line=270`  
> Никакого кодирования в `%D0%9E%D0%B1%D1%89...`, которое раздувает контекст диалога в 4–6 раз. Шлюз плагина нативно принимает и декодирует чистый UTF-8.

## 🚀 Быстрый старт

### 1. Установка плагина в 1C:EDT

#### Способ 1: Онлайн через Update Site (Рекомендуемый)
1. В 1C:EDT откройте: **Справка** (*Help*) → **Установить новое ПО...** (*Install New Software...*).
2. Нажмите кнопку **Добавить...** (*Add...*).
3. Заполните поля:
   - **Имя**: `1C:EDT URL Navigator`
   - **Расположение**: `https://vvi3ard.github.io/edt-url-navigator/`
4. Нажмите **Добавить** (*Add*).
5. В появившемся списке отметьте флажком **1C:EDT URL Navigator Feature**.
6. Нажмите **Далее** (*Next*), примите условия лицензии и нажмите **Готово** (*Finish*).
7. Перезапустите 1C:EDT по завершении установки.

> [!TIP]
> При выходе новых версий плагин обновляется автоматически: **Справка → Проверить наличие обновлений**.

#### Способ 2: Офлайн из архива (.zip)
1. Скачайте архив репозитория `com.github.vvi3ard.dt.navigator.repository-<версия>.zip` со страницы [GitHub Releases](https://github.com/VVi3ard/edt-url-navigator/releases).
2. В 1C:EDT откройте **Справка** → **Установить новое ПО...** → **Добавить...** → **Архив...** (*Archive...*).
3. Выберите скачанный `.zip` файл, отметьте `1C:EDT URL Navigator Feature` и завершите установку.

---

### 2. Установка мода в Claude Code

Откройте диалог с **Claude Code** и отправьте промпт из файла [SETUP-CLAUDE-CODE.md](SETUP-CLAUDE-CODE.md).

Claude Code самостоятельно:
1. Установит мод `edt-links`:
   ```bash
   claude plugin install edt-links --marketplace VVi3ard/edt-url-navigator
   ```
2. Пропишет правила оформления ссылок в ваш `~/.claude/CLAUDE.md`.

После этого в новых сессиях Claude Code каждое упоминание модуля, метода или объекта метаданных будет содержать кнопку `[EDT]`, мгновенно открывающую его в 1C:EDT.

---

## ⚙️ Настройки в 1C:EDT

После установки страница параметров доступна в меню:  
**Окно** (*Window*) → **Параметры** (*Preferences*) → категория **1C:EDT URL Navigator**.

Страница настроек содержит:
- **Локальный HTTP-сервер**:
  - Поле настройки порта (по умолчанию `18321`).
  - Индикатор текущего состояния (`● Сервер активен на 127.0.0.1:18321`).
  - Кнопка **«Проверить соединение с сервером»** — выполняет контрольный запрос `GET /health`.
- **Справка и установка**: прямая ссылка на репозиторий с документацией.

## 🔗 Поддерживаемые параметры и форматы ссылок

Ссылки в ответах Claude Code формируются в каноническом формате:  
`[Текст ссылки] ([EDT](http://127.0.0.1:18321/open?<параметры>))`

### Параметры URL-запроса:

| Параметр | Описание | Пример значения (на базе типовой БСП) |
| :--- | :--- | :--- |
| `module` | Полное имя модуля конфигурации 1С | `ОбщийМодуль.ОбщегоНазначенияКлиентСервер`, `Документ.ЗаказКлиента.МодульОбъекта` |
| `line` | Номер строки (1-based целое число) | `270` |
| `method` | Имя процедуры или функции (экспортной/локальной) | `ЗначениеРеквизитаОбъекта` |
| `md` | Имя объекта метаданных 1С (открывает редактор `.mdo`) | `Справочник.Номенклатура`, `Документ.ЗаказКлиента`, `Конфигурация` |
| `attr` | Реквизит, табличная часть, измерение или ресурс | `Артикул`, `СуммаДокумента`, `Курс`, `Товары` |
| `file` | Относительный путь к файлу в проекте EDT | `CommonModules/ОбщегоНазначенияКлиентСервер/Module.bsl` |
| `project`| *(Опционально)* Имя проекта воркспейса EDT | `МояКонфигурация` |
| `path` | *(Опционально)* Прямой абсолютный путь к файлу на диске | `C:/EDT/workspace/project/Module.bsl` |

### Примеры ссылок:

1. **Переход к модулю и строке:**
   ```markdown
   [ОбщегоНазначенияКлиентСервер (строка 270)](http://127.0.0.1:18321/open?module=ОбщийМодуль.ОбщегоНазначенияКлиентСервер&line=270)
   ```

2. **Переход к методу:**
   ```markdown
   [ОбщегоНазначения.ЗначениеРеквизитаОбъекта()](http://127.0.0.1:18321/open?module=ОбщийМодуль.ОбщегоНазначения&method=ЗначениеРеквизитаОбъекта)
   ```

3. **Модуль объекта документа / справочника:**
   ```markdown
   [ЗаказКлиента.МодульОбъекта:120](http://127.0.0.1:18321/open?module=Документ.ЗаказКлиента.МодульОбъекта&line=120)
   ```

4. **Объект метаданных и позиционирование на реквизит:**
   ```markdown
   [Справочник.Номенклатура -> Артикул](http://127.0.0.1:18321/open?md=Справочник.Номенклатура&attr=Артикул)
   ```

5. **Регистр сведений и ресурс:**
   ```markdown
   [РегистрСведений.КурсыВалют -> Курс](http://127.0.0.1:18321/open?md=РегистрСведений.КурсыВалют&attr=Курс)
   ```

6. **Относительный путь к файлу:**
   ```markdown
   [Module.bsl](http://127.0.0.1:18321/open?file=CommonModules/ОбщегоНазначенияКлиентСервер/Module.bsl&line=42)
   ```

Подробные спецификации описаны в [docs/LLM-LINKS-GUIDELINE.md](docs/LLM-LINKS-GUIDELINE.md).

## 🛠️ Сборка из исходников

Проект построен на базе **Eclipse Tycho / Maven**:

### Требования:
- JDK 17 или JDK 21 (x64)
- Apache Maven 3.9+
- Целевая платформа 1C:EDT (2026.1 / 2026.2)

### Сборка:
```bash
mvn clean verify -Dtycho.localArtifacts=ignore
```

Собранные артефакты:
- `bundles/com.github.vvi3ard.dt.navigator/target/com.github.vvi3ard.dt.navigator-*.jar`
- `repositories/com.github.vvi3ard.dt.navigator.repository/target/com.github.vvi3ard.dt.navigator.repository-*.zip`
- `repositories/com.github.vvi3ard.dt.navigator.repository/target/repository/` (готовый p2 update site)
