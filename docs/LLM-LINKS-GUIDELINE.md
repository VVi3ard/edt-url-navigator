# Правило генерации навигационных ссылок для 1C:EDT (System Prompt / Guideline для LLM)

Данное руководство описывает стандарт формирования кликабельных ссылок для мгновенной навигации разработчика в среде **1C:EDT** через плагин **1C:EDT URL Navigator**.

---

## 1. Базовые правила и схема URL

Ссылка на EDT добавляется **рядом** с обычной ссылкой, которую LLM формирует для своего харнесса (её формат не меняется):
`[обычная ссылка как обычно] ([EDT](http://127.0.0.1:18321/open?<параметры>))`

Все EDT-ссылки идут через HTTP-шлюз локального сервера плагина:
`http://127.0.0.1:18321/open?<параметры>`

> **Не используйте схему `edt://`**: в приложении Claude и ряде Markdown-рендереров такие ссылки не кликаются.

> [!IMPORTANT]
> **КАТЕГОРИЧЕСКИЙ ЗАПРЕТ PERCENT-ENCODING (`%D0%9E...`):**
> **Никогда не кодируйте русские буквы в `%XX`!**
> Все ссылки формируются **чистым текстом на русском языке в кодировке UTF-8**:
> - ✅ ПРАВИЛЬНО: `http://127.0.0.1:18321/open?module=ОбщийМодуль.ОбщегоНазначенияКлиентСервер&line=270`
> - ❌ ЗАПРЕЩЕНО: `http://127.0.0.1:18321/open?module=%D0%9E%D0%B1%D1%89%D0%B8%D0%B9...`
>
> Современные Markdown-парсеры и браузеры отлично поддерживают прямую кириллицу в ссылках, а кодирование `%XX` нерационально раздувает контекст в 4–6 раз и загрязняет текст. Плагин и его шлюз принимают чистый UTF-8 напрямую.

> **Форматирование в Markdown:**
> Ссылки всегда оформляются в стандартном Markdown-синтаксисе с осмысленным текстом:
> `[Текст ссылки](http://127.0.0.1:18321/open?...)`

## 2. Спецификация параметров

| Параметр | Описание | Пример значения |
| :--- | :--- | :--- |
| `module` | Полное имя модуля конфигурации 1С или путь к `.bsl` | `ОбщийМодуль.ОбщегоНазначенияКлиентСервер`, `Документ.ЗаказКлиента.МодульОбъекта` |
| `line` | Номер строки (1-based целое число) | `270` |
| `method` | Имя экспортной или локальной процедуры / функции | `ЗначениеРеквизитаОбъекта` |
| `md` | Объект метаданных 1С (открывает `.mdo`) | `Справочник.Номенклатура`, `Документ.ЗаказКлиента` |
| `attr` | Реквизит, измерение, ресурс или табличная часть | `Артикул`, `СуммаДокумента`, `Курс` |
| `file` | Относительный путь к файлу в проекте EDT | `CommonModules/ОбщегоНазначенияКлиентСервер/Module.bsl` |
| `path` | Прямой абсолютный путь к файлу на диске | `C:/EDT/.../Module.bsl` |
| `search` | *(Опционально)* Текстовый фрагмент для поиска и подсветки | `ОбменДанными.Загрузка` |
| `project`| *(Опционально)* Имя проекта в воркспейсе EDT, если имя есть в нескольких проектах | `МояКонфигурация` |

## 3. Сценарии использования

### 3.1. Ссылка на модуль целиком
Используется при упоминании общего модуля, модуля менеджера, объекта или формы:

* **Общий модуль:**
  `[ОбщийМодуль.ОбщегоНазначенияКлиентСервер](http://127.0.0.1:18321/open?module=ОбщийМодуль.ОбщегоНазначенияКлиентСервер)`
* **Модуль объекта документа/справочника:**
  `[Документ.ЗаказКлиента (МодульОбъекта)](http://127.0.0.1:18321/open?module=Документ.ЗаказКлиента.МодульОбъекта)`
* **Модуль менеджера:**
  `[Справочник.Номенклатура (МодульМенеджера)](http://127.0.0.1:18321/open?module=Справочник.Номенклатура.МодульМенеджера)`
* **Модуль набора записей регистра:**
  `[РегистрСведений.КурсыВалют (МодульНабораЗаписей)](http://127.0.0.1:18321/open?module=РегистрСведений.КурсыВалют.МодульНабораЗаписей)`
* **Модуль формы:**
  `[Форма документа ЗаказКлиента](http://127.0.0.1:18321/open?module=Документ.ЗаказКлиента.Форма.ФормаДокумента)`
* **Модули конфигурации:**
  `[МодульПриложения](http://127.0.0.1:18321/open?module=МодульПриложения)`
  `[МодульСеанса](http://127.0.0.1:18321/open?module=МодульСеанса)`

---

### 3.2. Ссылка на конкретную строку в модуле
Используется при указании мест ошибок, стека вызовов, диагностик или результатов анализа:

* `[ОбщийМодуль.ОбщегоНазначенияКлиентСервер:270](http://127.0.0.1:18321/open?module=ОбщийМодуль.ОбщегоНазначенияКлиентСервер&line=270)`
* `[Документ.ЗаказКлиента.МодульОбъекта (стр. 145)](http://127.0.0.1:18321/open?module=Документ.ЗаказКлиента.МодульОбъекта&line=145)`
* `[CommonModules/ОбщегоНазначенияКлиентСервер/Module.bsl:270](http://127.0.0.1:18321/open?file=CommonModules/ОбщегоНазначенияКлиентСервер/Module.bsl&line=270)`

---

### 3.3. Ссылка на метод (процедуру / функцию) в модуле
Используется, когда номер строки может сместиться при редактировании, но известно имя процедуры/функции. Плагин автоматически найдет определение метода (`Процедура <Имя>` / `Функция <Имя>`):

* `[ОбщегоНазначения.ЗначениеРеквизитаОбъекта()](http://127.0.0.1:18321/open?module=ОбщийМодуль.ОбщегоНазначения&method=ЗначениеРеквизитаОбъекта)`
* `[Документ.ЗаказКлиента -> ПередЗаписью()](http://127.0.0.1:18321/open?module=Документ.ЗаказКлиента.МодульОбъекта&method=ПередЗаписью)`
* `[ОбщегоНазначенияКлиентСервер.ЕстьРеквизитИлиСвойствоОбъекта()](http://127.0.0.1:18321/open?module=ОбщийМодуль.ОбщегоНазначенияКлиентСервер&method=ЕстьРеквизитИлиСвойствоОбъекта)`

---

* **Регистр сведений:**
  `[РегистрСведений.КурсыВалют](http://127.0.0.1:18321/open?md=РегистрСведений.КурсыВалют)`
* **Регистр накопления:**
  `[РегистрНакопления.ТоварыНаСкладах](http://127.0.0.1:18321/open?md=РегистрНакопления.ТоварыНаСкладах)`

### 3.5. Ссылка на реквизит, измерение или ресурс метаданных
Используется при указании конкретного поля объекта метаданных. Плагин открывает `.mdo` и позиционирует курсор на XML-тег `<name>ИмяРеквизита</name>`:

* **Реквизит справочника:**
  `[Справочник.Номенклатура -> Артикул](http://127.0.0.1:18321/open?md=Справочник.Номенклатура&attr=Артикул)`
* **Реквизит документа:**
  `[Документ.ЗаказКлиента -> СуммаДокумента](http://127.0.0.1:18321/open?md=Документ.ЗаказКлиента&attr=СуммаДокумента)`
* **Ресурс / Измерение регистра:**
  `[РегистрСведений.КурсыВалют -> Курс](http://127.0.0.1:18321/open?md=РегистрСведений.КурсыВалют&attr=Курс)`
* **Табличная часть:**
  `[Документ.ЗаказКлиента -> ТЧ Товары](http://127.0.0.1:18321/open?md=Документ.ЗаказКлиента&attr=Товары)`

## 4. Сводная таблица синтаксиса для LLM

```markdown
<!-- Модуль -->
[ОбщийМодуль.Имя](http://127.0.0.1:18321/open?module=ОбщийМодуль.Имя)

<!-- Модуль + Строка -->
[ОбщийМодуль.Имя:42](http://127.0.0.1:18321/open?module=ОбщийМодуль.Имя&line=42)

<!-- Модуль + Метод -->
[ОбщийМодуль.Имя -> Метод()](http://127.0.0.1:18321/open?module=ОбщийМодуль.Имя&method=Метод)

<!-- Метаданные -->
[Справочник.Имя](http://127.0.0.1:18321/open?md=Справочник.Имя)

<!-- Метаданные + Реквизит -->
[Справочник.Имя -> Реквизит](http://127.0.0.1:18321/open?md=Справочник.Имя&attr=Реквизит)```
